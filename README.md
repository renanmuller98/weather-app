<h1>WEATHER FORECAST ☀️</h1>

## 📱 Sobre

Weather Forecast é uma aplicação web que permite aos usuários verificar a previsão do tempo para diferentes localizações. A aplicação exibe informações detalhadas, incluindo umidade, velocidade do vento, temperatura máxima e mínima.

## 🎯 Funcionalidade

- Busca da previsão do tempo para qualquer localização.
- Exibição de dados meteorológicos, incluindo:
    - Umidade
    - Velocidade do vento
    - Temperatura máxima
    - Temperatura mínima
- Interface intuitiva e responsiva.

## 🛠️ Ferramentas Utilizadas

- React com Vite e TypeScript: Para a construção da interface de usuário e lógica do projeto.
- Sass: Para estilização avançada e modularização do CSS.
- Fetch API: Para consumir dados da API de previsão do tempo.

## 🤝 Como Contribuir

Contribuições são bem-vindas! Se você tem ideias de melhorias ou encontrou algum problema, sinta-se à vontade para abrir uma issue ou enviar um pull request.

Clone este repositório: 

```bash
git clone https://github.com/renanmuller98/weather-app.git
```
Navegue até o diretório do projeto:
```bash
cd weather-app
```

Instale as dependências:
```bash
npm install
```

Inicie o servidor:
```bash
npm run dev
```

Acesse a aplicação no navegador:
```bash
http://localhost:3000
```
